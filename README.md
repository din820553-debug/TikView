# TikView для Android

Отдельный неофициальный клиент веб-версии TikTok для Android 8.0+. Это исходники приложения, а не модифицированный APK TikTok.

**Версия 0.2.0:** компактная тёмная навигация, вкладки «Подписки» / «Для вас» и панель комментариев поверх видео. APK успешно собран: [скачать версию 0.2.0 — Artifacts → TikView-Android](https://github.com/din820553-debug/TikView/actions/runs/38874737170). Android Lint, 27 проверок URL/прокси и 8 проверок веб-адаптера прошли. Доступ из России и работа живого сайта на устройстве требуют отдельной проверки.

## Как получить APK через GitHub

1. Загрузите содержимое этого проекта в отдельный GitHub-репозиторий, включая `.github/workflows/android.yml`. `settings.gradle` должен лежать в корне репозитория.
2. Откройте **Actions → Build Android APK**. Сборка запускается при push; при необходимости разрешите Actions в настройках репозитория.
3. Дождитесь зелёной сборки. Внизу страницы запуска скачайте **Artifacts → TikView-Android** (нужен вход в GitHub).
4. Распакуйте ZIP, перенесите `app-debug.apk` на Android и разрешите установку для приложения, из которого открываете APK.

Это APK с отладочной подписью для личного тестирования. Подпись на новых чистых runner может меняться: при ошибке обновления удалите предыдущую установку (данные входа будут удалены). Для постоянного распространения нужен отдельный release keystore, сохранённый владельцем проекта.

## Подключение в России

Откройте приложение. Если сайт и ролики доступны через вашу сеть, настройки менять не нужно.

Если доступ ограничен, используйте свой системный VPN или укажите доверенный прокси в **Настройки**:

- `http://host:8080`
- `https://host:443`
- `socks://host:1080` (SOCKS5 в Android WebView)

Прокси должен быть действующим и находиться в сети, где TikTok доступен. Публичный сервер в приложение не встроен. Прокси с логином и паролем не поддерживаются. Пустое поле восстанавливает системное подключение. Настройка применяется к WebView этого приложения, а не ко всему телефону. При ошибке применения прокси приложение не начинает загрузку через прямое соединение.

Нужен актуальный **Android System WebView**. Если он не поддерживает Proxy Override, приложение предложит обновление или системный VPN. Доступность определяется сетью, IP, регионом аккаунта и ограничениями TikTok; прокси не гарантирует снятие всех ограничений. Не проверено из российской сети.

## Возможности

- Веб-версия TikTok, воспроизведение и полноэкранное видео.
- Открытие HTTPS-ссылок TikTok кнопкой «Ссылка» или через Android «Поделиться → TikView».
- Настройка прокси, повтор загрузки, очистка cookies и данных сайта.
- Выход за домены TikTok открывается в браузере после подтверждения.

Вход, рекомендации, капча и доступ к роликам зависят от поддержки TikTok в Android WebView. TikTok может потребовать официальный клиент или ограничить веб-версию. Приложение не использует частный API и не меняет регион аккаунта или SIM. Загрузка роликов на сервер, скачивание видео и встроенный VPN не реализованы.

## Комментарии

Откройте ролик и нажмите **💬 Комментарии** в нижней панели. Поддерживаемые кнопки комментариев на самом сайте также открывают эту панель. Для ленты выбирается ссылка именно видимого видео; если страница её не предоставляет, откройте прямую ссылку на ролик кнопкой «Ссылка».

Комментарии загружаются с полной веб-страницы того же видео в отдельной панели снизу, через то же подключение и cookies. Пока панель открыта, видео на основной странице ставится на паузу. Панель закрывается крестиком, нажатием на затемнённую область или кнопкой «Назад».

Когда сайт отрисует список комментариев, он подстраивается под ширину телефона. Если TikTok показывает вход, капчу, отключённые комментарии или изменённую разметку, отображается страница сайта. **«Вся страница»** отключает выделение списка и перезагружает страницу. Вход через доступные на сайте методы может понадобиться для ответа; переходы на сторонние страницы авторизации в этой панели не поддерживаются. Приложение не гарантирует доступ к комментариям, если сам TikTok ограничивает веб-версию.

## Данные и разрешения

Единственное разрешение — интернет. Cookies и адрес прокси хранятся локально; резервное копирование отключено. Нет JavaScript-моста к Android, доступа к файлам устройства, аналитики и отключения TLS-проверок. Контент и данные входа обрабатывает сайт TikTok. Используйте только доверенный прокси.

## Сборка

Требуются JDK 17, Gradle 8.9, Android SDK Platform 35 и Build Tools 35.0.0. GitHub Actions устанавливает их автоматически. Wrapper в проект не включён, workflow использует закреплённую версию Gradle.

```sh
gradle --no-daemon :app:lintDebug :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Проверка разрешённых URL и формата прокси (27 случаев) без Android SDK:

```sh
mkdir -p /tmp/tikview-checks
javac -d /tmp/tikview-checks app/src/main/java/dev/tikview/UrlPolicy.java checks/UrlPolicyCheck.java
java -cp /tmp/tikview-checks dev.tikview.UrlPolicyCheck
```

Проверки выполнены в GitHub Actions: все 27 случаев прошли, Android Lint и сборка APK завершились успешно. Локальная облачная среда не использовалась для сборки.

Проверка определения активного видео и адаптации комментариев:

```sh
node --test checks/web-adapter.test.cjs
```
